## 1. 本次任务概述

本次基于 `petrochemical-rule-extraction` skill，对课题四知识规则库补充资料进行整本文件解析、规则识别、规则结构化和结果一致性校验。最终形成 1 个 Excel 汇总表和 5 类 JSON 规则文件。

本次抽取覆盖 5 类规则对象：

1. 质量标准规则
2. 工艺规范规则
3. 流程特征规则
4. 操作规程规则
5. 调度经验规则

## 2. 前期 Skill 更新内容

为满足本次抽取要求，已对 `petrochemical-rule-extraction` skill 做了以下更新：

1. 抽取对象由原先偏向单类规则扩展为 5 类规则：质量标准类、工艺规范类、流程特征类、操作规程类、调度经验类。
2. 按《课题4规则规模评估-知识规则示例.docx》的对象体系补充了各类规则子类型和识别重点。
3. 统一了 JSON 顶层字段，字段参考 `工艺规范规则.json`，每条规则包含：

   ```text
   rule_id, rule_name, knowledge_type, sub_type, applicable_scope,
   rule_content, source_file, locator, evidence_text, parameters,
   devices, operations, conditions, constraint_type, notes
   ```

4. 更新 Excel 输出模板，`extracted_rules.xls` 固定包含 5 个子表：

   ```text
   1、质量标准规则
   2、工艺规范规则
   3、流程特征规则
   4、操作规程规则
   5、调度经验规则
   ```

5. 明确最终规则表字段顺序：

   ```text
   规则编号, 规则名称, 知识类型, 子类型, 适用范围,
   规则内容, 来源文件, 具体页码, 原文内容, JSON, 备注
   ```

6. 增加扫描件 PDF 解析能力，支持通过 OCR 解析图片型 PDF；默认使用 `claude` conda 环境中的 OCR 依赖，中文扫描件优先使用 `chi_sim+eng`。
7. 增加整本 PDF 转中文 DOCX 能力，支持将文本型 PDF、扫描 PDF、英文 PDF 转为按页定位的中文 DOCX，再基于 DOCX 抽取规则。
8. 增加英文资料中文化处理要求，英文资料在解析阶段转换为中文语义后再进入规则抽取流程。
9. 增加 `scripts/extract_rules_from_docs.py`，用于从 `parsed_docx` 或文本 PDF 中一次性抽取 5 类规则并生成 Excel 与 JSON。
10. 增加 `scripts/pdf_to_chinese_docx.py`，用于整本 PDF 解析、OCR 和英文转中文 DOCX。
11. 增加 `scripts/ocr_scanned_pdf.py`，用于扫描 PDF OCR 文本块解析。
12. 增加 `scripts/sync_excel_from_json.py`，用于在 5 类 JSON 已更新时，以 JSON 为唯一数据源重建并校验 `extracted_rules.xls`，确保 Excel 和 JSON 内容一致。

## 9. 质量控制说明

本次抽取重点控制以下问题：

1. 规则内容不直接复制长篇原文，而是整理为结论式规则。
2. 每条规则保留来源文件和页码定位，便于后续人工核验。
3. 每条规则保留最小充分原文证据，便于追溯。
4. JSON 字段不包含 `mask`、`confidence`、人工核验等非抽取字段。
5. Excel 与 JSON 已按 JSON 为唯一数据源重新同步，避免表格与 JSON 不一致。

## 10. 主要风险与后续建议

1. 部分 PDF 为英文资料或扫描/图片型资料，OCR 和翻译质量可能影响页码定位、单位识别和专业术语表达。
2. 部分规则来源于教材或论文的归纳表达，后续进入正式知识库前建议进行专家核验。
3. 对涉及安全红线、质量边界、工艺阈值的规则，建议重点复核参数方向、单位和适用范围。
4. 当前规则数量已满足规模要求，但部分子类型数量较少，如加氢装置协同规则、原料罐区操作规程等，后续可补充对应专题资料提升覆盖度。
5. 若后续人工修改 5 类 JSON，应重新运行 `scripts/sync_excel_from_json.py` 同步 Excel，保持 `extracted_rules.xls` 与 JSON 一致。
