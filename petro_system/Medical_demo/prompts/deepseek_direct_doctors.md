要求：

1. 可以基于模型已有知识直接输出医生，不要求网页来源链接。
2. 优先选择候选医院中与候选科室、患者主诉、疑似诊断或检查异常更相关的医生。
3. 医生姓名必须写具体姓名；不知道职称、擅长方向或来源链接时可以留空。
4. hospital 必须来自 candidate_hospitals，不要输出候选医院之外的医院。
5. 不输出诊断、治疗方案、费用、号源或保证性表述。

```json
{
  "doctor_evidence": [
    {

      "source_url": ""
    }
  ]
}
```
