本周也把 JSON 导出流程进一步固定下来，简化后可以理解为：

```text
1. 从主总表的“最终交付表”读取规则数据
2. 检查规则编号和必需字段，过滤空行或无效项
3. 按统一结构映射为标准 JSON 规则对象
4. 按所属大类拆分输出分类文件
5. 汇总生成 规则库_当前版.json 和 index.json
6. 执行自动核验，确认数量、编号和关键字段一致
```

对应代码路径：
- 源表路径：`提取结果/01_当前结果/主总表.xlsx`
- 导出脚本：`scripts/export_rules_to_json.py`
- 核验脚本：`scripts/validate_rule_library.py`

当前执行标准主要是：
- 以 `最终交付表` 作为导出主口径
- JSON 统一使用 `UTF-8` 编码
- 当前库按大类拆分维护，汇总文件自动生成
- 导出完成后必须再跑核验，不直接把草稿当正式结果使用
