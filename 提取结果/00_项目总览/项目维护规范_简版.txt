项目维护规范（简版）

一、当前正式入口
1. 表格正式入口：`01_当前结果`
2. 过程追溯入口：`02_过程追溯`
3. JSON 维护入口：`..\json规则库\current\`
4. JSON 汇总输出：`..\json规则库\规则库_当前版.json`

二、维护顺序
1. 先修改表格主源
2. 再同步 JSON 分类文件
3. 然后执行导出和核验
4. 最后补变更记录和历史快照

三、不要这样做
1. 不要回写 `90_历史归档`
2. 不要直接改 `历史草稿与参考样例\规则库.json`
3. 不要把 `规则库_当前版.json` 当作手工维护源
4. 不要同时维护多份“当前版”

四、出现问题时怎么处理
1. 先核对 `01_当前结果` 中的正式表格
2. 再核对 `json规则库\current\` 是否同步
3. 再看自动核验报告和变更记录
4. 最后再回查归档区和历史草稿
