## 不参考文件

已废止或本轮不参考文件见 `废止不参考/`。这些文件只作为资料收集记录，不参与规则提取、规则核验或规则库构建。

## 维护规则

- 新增标准前先确认标准状态。
- 现行且本轮使用的文件放在本目录根目录。
- 废止、替代、仅作背景参考的文件放入 `废止不参考/`。
- 规则提取记录中必须写明具体源文件路径和标准状态。
