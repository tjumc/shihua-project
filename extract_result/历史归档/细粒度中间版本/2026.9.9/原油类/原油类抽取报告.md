# 原油类抽取报告

## 1. 原油类规则提取程度分析表

| 规则 | 提取程度 | 可提取内容 | 缺失内容 | 建议 |
|---|---|---|---|---|
| 原油罐物料平衡 | 可计算抽取 | 原油罐、初始库存 | 时段长度、独立损耗参数未给出 | 可抽取，但不是本次重点 |
| 原油罐收付互斥 | 缺失 | 可识别原油罐对象 | 无收付互斥参数 | 暂不抽取 |
| 原油罐库存上下限 | **可计算抽取** | 安全高度上下限、米系数、库存上下限 | 无关键缺口 | **本次重点抽取** |
| 单罐同时供料装置数量 | 缺失 | 可识别原油罐和常压装置 | 无最大同时供料装置数、有效供料流率阈值 | 暂不抽取 |
| 原油罐静置 | 缺失 | 可识别原油罐对象 | 无最小静置时间 | 暂不抽取 |
| 付油罐切换 | 缺失 | 可识别常压装置和原油罐 | 无切换次数、调度周期、候选罐范围 | 暂不抽取 |
| 原油混合总量 | 部分可提取 | 可定义混合物料守恒关系 | 无实际混流器及进出料关系 | 暂不抽取 |
| 原油混合性质计算 | 部分可提取 | YCO、RCO 的 API、比重、硫含量、酸值 | 无实际混流器、流股、周期，部分性质单位不明确 | 可抽性质参数，但不是本次重点 |
| 原油混合侧线收率计算 | **可直接抽取** | 两套常压装置、5条侧线、YCO/RCO质量收率 | 无关键缺口 | **本次重点抽取** |
| 单装置同时供油罐数量上下限 | 缺失 | 可识别常压装置和原油罐 | 无供油罐数量上下限、有效连接流率阈值 | 暂不抽取 |
| 原油罐收油速率上下限 | 缺失 | 可识别原油罐对象 | 无收油速率上下限 | 暂不抽取 |
| 进厂原油在期限内全部收完 | 缺失 | 无完整到货事件数据 | 无到货时间、截止时间、剩余量 | 暂不抽取 |
| 原油收油罐选择 | 缺失 | 可识别原油罐集合 | 无批次与储罐相容关系 | 暂不抽取 |

### 提取程度说明

- **可直接抽取**：参数和对象均明确，可直接形成规则。
- **可计算抽取**：基础参数明确，可通过固定公式得到规则参数。
- **部分可提取**：只能提取部分对象或参数，不能形成完整规则。
- **缺失**：关键参数或关系缺失，暂不生成规则。

## 3. 原油罐库存上下限

### 3.1 计算总规则

```text
库存下限 = 安全高度下限 × 米系数
库存上限 = 安全高度上限 × 米系数
```

```json
  "sets": [
    {
      "set_name": "T",
      "subset_name": null,
      "element": null
    }
  ],
  "parameters": {}
}
```

## 4. 原油混合侧线收率计算

### 4.1 计算总规则

```text
侧线流量 = Σ(原油进料流量 × 对应质量收率)
```

总规则：

```json
{
  "rule_id": "CRUDE_MIX_SIDECUT_YIELD_CALC",
  "description": "CDU侧线流量等于各原油进料流量与对应侧线质量收率乘积之和。",
  "sets": [
    {
      "set_name": "O",
      "subset_name": null,
      "element": null
```
