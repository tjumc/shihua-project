# 系统运行说明

## 启动网页

```bash
cd /Users/machong/shihua-project/petro_system
backend/.venv/bin/python app.py
```

浏览器访问 `http://127.0.0.1:7860`。

## 数据库维护

```bash
cd /Users/machong/shihua-project/petro_system/backend

# 查看数据库统计
.venv/bin/python -m petro_rules.cli stats

# 校验数据库
.venv/bin/python -m petro_rules.cli validate

# 使用正式表重新导入
.venv/bin/python -m petro_rules.cli import
```

正式 Excel 的默认位置为：

`/Users/machong/shihua-project/data/tables/五类规则正式提交表_1050条.xlsx`
