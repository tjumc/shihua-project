# 文件保留与清理规则

更新日期：2026-06-03

## 保留原则

本项目需要长期维护，文件清理以“不丢证据链”为前提。原始资料、提取结果、核验结果、周报归档和交付快照原则上保留，不因文档中心整理而删除。

## 文件分类

| 类型 | 处理方式 | 典型位置 |
| --- | --- | --- |
| 原始资料 | 保留，作为规则来源和核验依据 | `延长数据/`、`石化通用规则源文件/` |
| 当前成果 | 保留并持续更新 | `提取结果/01_当前结果/`、`json规则库/current/` |
| 过程追溯 | 保留，用于解释规则如何形成 | `提取结果/02_过程追溯/`、`提取结果/04_截图追溯/` |
| 周报归档 | 保留，按周次存放 | `提取结果/00_项目总览/周报归档/` |
| 可读文档入口 | 放入 `docs/`，保持浅层结构 | `docs/项目总览/`、`docs/周报汇报/`、`docs/规则与核验/` |
| 重复说明文件 | 合并到 `docs/` 后，可删除旧入口 | 旧版单独说明文档 |
| 废止标准 | 单独隔离，不参与规则提取 | `石化通用规则源文件/废止不参考/` |
| 软件临时文件 | 不作为正式资料，不提交 Git | `.DS_Store`、`.obsidian/` |

## 当前口径

- `docs/` 是阅读入口，不替代 `提取结果/` 和源文件目录。
- `提取结果/01_当前结果/` 是当前成果入口。
- `json规则库/current/` 是 JSON 分类维护入口。
- `石化通用规则源文件/` 根目录只放现行可参考标准。
- 已废止或本轮不参考的标准统一放入 `石化通用规则源文件/废止不参考/`。

## 清理边界

可以清理：

- 明确重复、且内容已合并到 `docs/` 的旧文档入口。
- 系统自动生成的 `.DS_Store`。
- Obsidian 的工作区状态文件。

不建议清理：

- 原始 PDF、Word、报表、截图。
- Excel 提取结果和核验结果。
- 周报归档和交付快照。
- 历史计划文档和变更记录。
