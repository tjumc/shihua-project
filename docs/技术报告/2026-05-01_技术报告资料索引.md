# 2026-05-01 技术报告资料索引

## 1. 用途

本文件用于记录“PDF 规则提取技术报告”优先引用的资料，避免后续写作时再次分散查找。

## 2. 正式链路资料

以下资料应作为技术报告的主证据链：

- `提取结果/01_当前结果/主总表.xlsx`
  当前规则提取和整理的正式主表
- `提取结果/01_当前结果/终版审计表.xlsx`
  当前正式审计口径
- `json规则库/规则库_当前版.json`
  当前聚合后的 JSON 规则库
- `json规则库/current/`
  当前按大类拆分维护的 JSON 规则文件
- `json规则库/index.json`
  当前分类索引

## 3. 过程追溯资料

以下资料适合用于说明方法和质量控制过程：

- `提取结果/02_过程追溯/01_原始审计/提取内容逐项审计.xlsx`
  原始逐项审计记录
- `提取结果/02_过程追溯/02_二次收敛/`
  二次收敛材料
- `提取结果/02_过程追溯/03_结构样例/`
  结构样例和口径说明
- `提取结果/02_过程追溯/04_覆盖检查/`
  小项覆盖检查材料
- `提取结果/02_过程追溯/05_规则追溯核对/2026-04-30_规则追溯核对结论.md`
  当前正式链路核对结论
- `提取结果/02_过程追溯/05_规则追溯核对/2026-04-30_重复规则口径判定结论.md`
  重复规则口径判定结论

## 4. 自动化与脚本资料

以下资料适合用于说明半自动化部分：

- `scripts/export_rules_to_json.py`
  将正式主表导出为 JSON 规则库
- `scripts/validate_rule_library.py`
  对正式链路和 JSON 规则库做自动核验
- `docs/规则库自动核验方案.md`
  自动核验方案说明
- `提取结果/02_过程追溯/05_规则追溯核对/自动核验/2026-04-30_规则库自动核验报告.json`
  自动核验结果
- `提取结果/02_过程追溯/05_规则追溯核对/自动核验/2026-04-30_规则库自动核验报告.md`
  自动核验摘要报告

## 5. 项目概览资料

以下资料适合用于技术报告的背景和阶段成果说明：

- `AGENT_CONTEXT.md`
  项目交接和当前工作口径说明
- `提取结果/00_项目总览/当前状态一页纸.md`
  当前阶段结论和风险摘要

## 6. 写作建议

1. 讲“方法”时，优先引用正式链路资料和过程追溯资料。
2. 讲“可信性”时，优先引用审计表、核对结论和自动核验报告。
3. 讲“自动化”时，不把脚本描述成完全自动提取，而应描述为对结构化整理和一致性核验的支持工具。
