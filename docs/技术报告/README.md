# 技术报告档案

更新日期：2026-05-01

## 1. 目录用途

本目录用于集中维护“PDF 规则提取技术报告”相关材料，和周报、团队汇报稿、规则核对过程材料分开保存。

建立这个目录的目的有 3 个：

- 固定技术报告的写作入口，避免材料再次分散
- 沉淀本项目从 PDF 到规则库的正式技术说明
- 为后续团队成员或其它 agent 提供可复用的阅读入口

## 2. 当前文件说明

- `README.md`
  说明本目录的用途、维护规则和文件角色
- `2026-05-01_技术报告资料索引.md`
  记录技术报告拟引用的正式资料、过程资料和自动化产物
- `2026-05-01_PDF规则提取技术报告_大纲.md`
  记录技术报告的建议结构、章节目标和写作重点

## 3. 维护规则

1. 本目录只放技术报告相关文件，不混入周报、汇报稿或临时截图。
2. 报告写作优先引用正式链路文件，其次才引用过程材料。
3. 新增文件统一使用日期开头，便于后续追踪版本。
4. 如果后续形成正式技术报告正文，建议与大纲、资料索引并列保存，不覆盖原始准备文件。

## 4. 后续建议

后续可继续补充以下内容：

- 技术报告正文
- 图表草稿
- 术语说明
- 报告修订记录
