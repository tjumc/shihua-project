# docs 文档中心

这里是项目文档中心，用于快速阅读项目状态、周报、规则提取、核验流程和 Skill 说明。

## 目录

| 目录 | 内容 |
| --- | --- |
| `项目总览/` | 项目当前状态、目录规范、推荐阅读顺序 |
| `周报汇报/` | 周报和汇报稿 |
| `规则与核验/` | 通用规则、核验总结、自动核验方案 |
| `Skill说明/` | 核验 Skill、增量更新 Skill 说明 |
| `技术报告/` | 技术报告草稿与资料索引 |
| `参考资料/` | 参考资料说明 |
| `plans/` | 历史计划文档 |

## 推荐入口

1. `项目总览/项目当前状态.md`
2. `项目总览/推荐阅读顺序.md`
3. `周报汇报/2026-06-03_周三汇报.md`
4. `规则与核验/通用知识规则当前结果.md`
5. `项目总览/文件保留与清理规则.md`
