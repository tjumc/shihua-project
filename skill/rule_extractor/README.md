# 石化调度知识规则提取 Skill v3

这是一个面向**多文件/文件夹**的石化调度知识规则抽取 Skill。

## 核心变化

新版不再把 DOCX/PDF/MD/XLSX 混在一起直接抽，而是：

1. **先递归梳理全部文件**，判断每个文件大概能提取哪些大类/子类，并给优先级；
2. **原生数据表格优先**（XLSX/XLS/CSV/TSV），先建立规则底座；
3. 使用 `规则数26-V3_规则数量整理.xlsx` 作为数量覆盖基线；
4. 表格首轮后计算每个 target group 的已提取唯一规则数和剩余量；
5. 只有仍有缺口的子类/实体槽位才允许进入 DOCX/PDF/MD 补缺；
6. 已达标/已覆盖的子类，后续文本只做复核/冲突检测，不重复生成；
7. 去重后再统计数量；
8. 最终仍输出8大类JSON、8-sheet Excel和总提取报告。

## 唯一 JSON 模板

`references/知识规则模版.md`

每条最终规则**必须且只能**：

```json
{
  "rule_id": "...",
  "description": "...",
  "sets": [],
  "parameters": {}
}
```

## 四个控制参考

- `规则数26-V3(1).docx`：范围/实体粒度
- `知识规则模版.md`：逐子类四字段 JSON、sets、parameters
- `调度专项符号统一说明-V1.docx`：符号和公式
- `规则数26-V3_规则数量整理.xlsx`：数量覆盖/剩余量控制

## 多文件输出增加

除最终8个JSON/Excel/报告外，还会生成：
- `source_inventory.json`
- `文件梳理与提取计划.md`
- `rule_gap_after_tables.json`
- `剩余规则补缺计划.md`

## 重要原则

**数量是覆盖控制工具，不是凑数工具。**

- exact 达标：停止新增；
- 约数/区间：只作指导；
- 证据不足：保持 missing；
- 超目标：先查重复、实体粒度、分类错误；
- 同一事实来自多个文件：合并证据，不重复输出。
