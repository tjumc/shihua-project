# 石化规则抽取与核验项目

本仓库用于维护石化项目的规则抽取、规则核验、JSON 规则库、通用知识规则和周报汇报材料。

## 推荐入口

日常查看项目，不需要从深层目录开始翻，先看下面几个文件：

| 目的 | 入口 |
| --- | --- |
| 了解项目现状 | `docs/项目总览/项目当前状态.md` |
| 查看阅读顺序 | `docs/项目总览/推荐阅读顺序.md` |
| 查看目录规范 | `docs/项目总览/目录规范.md` |
| 查看文件保留规则 | `docs/项目总览/文件保留与清理规则.md` |
| 查看本周项目周报 | `docs/周报汇报/2026-06-09_项目周报.md` |
| 查看通用知识规则 | `docs/规则与核验/通用知识规则当前结果.md` |

## 顶层目录

| 目录/文件 | 用途 |
| --- | --- |
| `docs/` | 文档中心，放项目总览、周报汇报、规则说明、核验方案和 Skill 说明 |
| `提取结果/` | 当前 Excel 成果、审计表、核验结果、周报归档和交付快照 |
| `json规则库/` | 当前 JSON 规则库、分类 JSON、历史版本和模板说明 |
| `延长数据/` | 项目方原始资料，包括操作规程、报表、截图、应急预案等 |
| `石化通用规则源文件/` | 通用知识规则使用的国家标准、行业标准等源文件 |
| `scripts/` | JSON 导出、规则库校验和维护脚本 |
| `skill documents/` | 规则核验 Skill 原始文档和脚本 |
| `5.27规则内容更新skill/` | 规则增量更新 Skill 与模拟实验材料 |
| `AGENT_CONTEXT.md` | 给自动化助手使用的项目上下文 |
| `PROJECT_MANIFEST.csv` | 早期文件清单快照；日常查看以 `docs/` 文档中心为准 |

## 常用脚本

```bash
python scripts/export_rules_to_json.py
python scripts/validate_rule_library.py
```

如果本机缺少 `openpyxl`，规则库校验脚本会无法运行；需要先补齐 Python 依赖。

## 维护原则

- 新增可读文档优先放入 `docs/`。
- Excel、PDF、截图和过程产物仍放在 `提取结果/` 或源文件目录，不放入 `docs/`。
- 新周报先写入 `docs/周报汇报/`，完整归档仍保留在 `提取结果/00_项目总览/周报归档/`。
- 已废止标准不作为规则来源，统一放入 `石化通用规则源文件/废止不参考/`。
- `.DS_Store`、`.obsidian/` 等本地软件临时文件不作为正式项目资料。
- 上传 GitHub 前确认仓库权限，本项目包含业务源文件、报表、规程和截图。
