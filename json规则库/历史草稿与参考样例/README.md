# 历史草稿与参考样例说明

更新日期：2026-05-06

这个目录只用于保存 JSON 规则库相关的旧草稿和参考样例，不作为当前正式维护入口，也不作为当前机器使用入口。

当前包含：

- `规则库.json`
  旧草稿，存在编码或结构合法性问题，仅保留供回看，不可直接作为正式版本继续维护。

- `延长数据_规则库.json`
  从 `延长数据/` 中移出的旧本地草稿，保留原始内容供回看，不再继续追加。

- `refinery_knowledge_rules.json`
  参考样例，偏建模/规划规则表达，可作为结构参考，但不参与当前正式链路。

当前正式入口：

- 维护源：`../current/`
- 分类索引：`../index.json`
- 汇总输出：`../规则库_当前版.json`

维护提醒：

- 不要直接在这里的历史草稿上继续追加维护。
- 不要把这里的文件当作当前正式 JSON 对外使用。
- 如需更新规则，先改表格主源，再更新 `../current/`，最后重新生成 `../规则库_当前版.json`。
