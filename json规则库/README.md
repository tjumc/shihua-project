# JSON 规则库工作区

更新日期：2026-04-29

## 1. 目录用途

这个目录用于维护“已提取规则”的 JSON 版本，不直接替代表格主源。

维护原则：

- 表格主源优先
- JSON 规则库作为受控输出维护
- 当前工作版只保留一份
- 历史版本只追加，不覆盖

## 3. 推荐维护流程

1. 在表格主源中确认规则内容。
2. 按正式模板整理或更新 `current/` 下的分类文件，或从表格主源重新导出。
3. 校验 JSON 合法性。
4. 记录本次变更到 `规则库_变更记录.md`。
5. 生成带日期和版本号的历史快照。

## 4. 不建议的做法

- 不要直接在旧的 `规则库.json` 草稿上继续追加
- 不要同时维护多份“当前版”
- 不要先改 JSON 再回头补表格
- 不要不留版本记录直接覆盖当前文件
- 不要把 `规则库_当前版.json` 当作手工维护源，它现在是自动汇总文件
