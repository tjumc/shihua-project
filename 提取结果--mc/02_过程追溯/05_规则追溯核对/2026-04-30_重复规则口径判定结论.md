# 2026-04-30 重复规则口径判定结论

## 1. 判定目的

这份结论用于回答一个问题：

- 当前规则库里的“重复”到底是错误重复，还是允许按不同知识目标重复建模

本次判定不直接改动规则数量，只给出后续维护口径。

配套清单见：

- `02_过程追溯/05_规则追溯核对/2026-04-30_重复规则口径判定清单.xlsx`

## 2. 总体原则

本轮建议采用 3 条判断规则：

1. 跨大类但服务于不同知识目标的同一句原文，可以双口径保留。
2. 同名但对象或场景不同的规则，不合并，直接改名。
3. 同名、同页、同对象且内容高度重叠的规则，不建议按现状双留，应合并或重写区分。

## 3. 判定结果

### 3.1 建议保留双口径

这类条目虽然内容重复，但服务于不同知识目标。

#### 组 G1

- `规则092`：操作规程规则 / 物料收付、调合、输送安全操作
- `规则161`：流程特征规则 / 装置间物料平衡

建议：

- 保留双口径
- 后续如要做唯一规则统计，应把这两条标记为“同源复用”

原因：

- 前者强调反输操作要求
- 后者强调物料流向和平衡关系

#### 组 G2

- `规则131`：操作规程规则 / 采样、分析、质量控制操作规范
- `规则151`：流程特征规则 / 上下游协同逻辑

建议：

- 保留双口径
- 后续如要做唯一规则统计，应把这两条标记为“同源复用”

原因：

- 前者强调放行前质量控制动作
- 后者强调调和结束到销售/出厂之间的协同放行逻辑

### 3.3 建议合并或重写区分

#### 组 G6

- `规则163`
- `规则194`

当前问题：

- 同名：`混合柴油质量标准规则`
- 同来源文件、同页码、同适用范围
- 当前内容高度重叠
- 但被放进了 `产品质量标准` 和 `组分质量标准` 两个小项

建议：

- 不建议按现状双留
- 优先做人工复判

处理优先顺序：

1. 如果本意只是“混合柴油产品标准”，保留 `规则163`，合并或删除 `规则194`
2. 如果确实需要保留“组分指标”口径，则必须把 `规则194` 重写成明确的组分/指标表述，并改名为 `混合柴油组分指标规则`

## 4. 当前建议的执行顺序

1. G3 / G4 / G5 的改名已完成，不再作为当前待办
2. 优先处理 G6，因为它仍是最像真正重复计数风险的一组
3. 最后决定是否在项目里正式引入“同源复用”标记，用于 G1 / G2 这类跨大类重复语义规则

## 5. 如果继续执行

下一步最稳妥的做法是：

1. 维持当前 `215` 条口径不变，先不动计数
2. 单独对 `规则163 / 规则194` 做一次人工判定
3. 若后续确认 G1 / G2 长期保留双口径，建议补充“同源复用”标记
