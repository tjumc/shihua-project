新目录入口说明

从 2026-04-29 起，项目开始进入“新框架过渡期”。

本阶段原则：
1. 新建长期维护目录和团队汇报入口。
2. 复制当前正式入口到新目录。
3. 旧入口目录已整体移入过渡归档区，不再作为根目录工作入口。

建议优先使用的新入口：
1. 00_项目总览
2. 01_当前结果
3. 02_过程追溯
4. 99_交付快照

当前维护约束：
1. 正式结果只在新目录中维护，不再回写旧结构。
2. 表格主源以 `01_当前结果` 为准。
3. JSON 维护以 `..\json规则库\current\` 为准，`规则库_当前版.json` 只作为汇总输出，不作为手工维护源。
4. 如需查历史，只查阅 `90_历史归档`，不在其中继续新增或修改。

旧目录说明：
1. 原有 总表、终版交付包、需人工确认、页面截图、历史版本归档 已移入 `90_历史归档\过渡期旧结构_2026-04-29`。
2. 根目录原有 `当前使用说明.txt`、`说明.txt` 也已移入同一归档目录。
3. 这些旧目录和旧说明文件仍可查阅，但不应继续作为维护入口。
4. 后续新增维护应只进入新目录。

推荐维护顺序：
1. 先更新 `01_当前结果` 中的正式表格。
2. 再同步更新 `..\json规则库\current\`。
3. 然后重新生成 `规则库_当前版.json` 并执行核验。
4. 最后补充变更记录和历史快照。
